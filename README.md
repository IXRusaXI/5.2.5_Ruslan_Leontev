# 5.2.5 URL-параметры и search-параметры 

Page: https://ixrusaxi.github.io/5.2.5_Ruslan_Leontev/

Так как мы не используем реальные вакансии из HeadHunter, то лимит страницы был уменьшен до 4 для наглядности.
Этот лимит можно изменить централизовано в файле src/store/slices/page/pageSlice.ts в переменной pageLimit. При изменении лимита все будет так-же работать, но нужно будет нагенерировать больше вакансий для демонстрации пагинации при фильтрации и без.

Обращаю внимание на начальный набор скиллов(в соответствии с требованиями задачи 4.2.3). Для отображения полного набора вакансий, необходимо удалить все скиллы из фильтра.
